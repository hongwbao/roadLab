# 红绿灯

红绿灯是可选的路口控制功能；未添加信号灯的路口沿用原有预测让行。计时、车辆准入、地图操作和渲染分别放在独立模块中，不将相位状态机写入主模拟循环。

## 操作

点击左侧红绿灯工具或按 K，选择三岔及以上路口的中心，再点击“添加红绿灯”。右侧浮层显示当前相位、绿／黄／全红状态和剩余模拟时间。地图上的灯头区分左转与直行／右转，停止线位于斑马线前。

可选两种配相：

- **直行／左转分相**：将近似对向的进口分组，直行与右转同时放行，左转使用独立相位。默认通行绿灯 20 秒、左转 8 秒。
- **逐进口轮放**：每次允许一个进口的所有可用转向，适合共用转向车道较多的路口。

自动配相只包含实际可达的车流方向，没有对应道路的相位不会生成。修改车道转向规则或道路连接后重新生成相位。红灯禁止右转；尚未实现红灯右转、行人相位、感应控制和手工逐车道相位编排。

“黄灯、清空与协调”可调整黄灯、全红最短时间和启动偏移。默认黄灯 3 秒、全红 2 秒；这些是游戏参数。所有计时使用模拟时间，暂停会停表，1×／2×／4×同步生效。修改设置会重置交通测试，不在正在通过的车辆中间直接切换方案。

点击“移除红绿灯”或在此工具中右键点击路口，可恢复无灯控制。添加、修改和移除均支持撤销重做，配置随地图保存。K 或 Esc 退出工具。

## 行车规则

车辆先检查当前方向是否获准，再检查目标车道能否接收整车。绿灯不会让车辆挤入已满的出口。已有跟车、预测让行和实际车身保护始终保留。

红灯车辆在停止线前制动。信号预判距离按当前速度和舒适制动距离扩展，不限于普通连接的 80 米预判范围。黄灯期间，能正常停车的车辆停车；距离过近、无法舒适停车且能在剩余黄灯时间内抵达的车辆可继续通过。

车辆实际越过停止线后记录已获准入，即使随后变灯，也继续驶离路口。若实际车身保护撤销该次移动，新增加的准入记录也撤销，避免错误地绕过红灯。停止线位于路口裁切边界外 4.5 米，停车判断包含车长和跟车净距。

每个相位结束后先经历黄灯，再进入全红清空。最短全红时间结束时，如还有已获准或正在转弯的车辆未清空，继续保持全红；清空后才放行下一相位。正常绿灯内允许同一相位的多股车流并行，不因路口里出现任意一辆车就封锁整个路口。

正常等红灯不会作为死锁候选或仅因停车而触发改道。预测轨迹包含红灯停止线，换相时释放对未获准车流的旧让行承诺，避免绿灯车辆一直等红灯车辆先走。

## 模块边界

| 文件                               | 负责内容                                           |
| ---------------------------------- | -------------------------------------------------- |
| `src/core/traffic-signals.ts`      | 保存的数据结构、默认配置、路口绑定、导入校验及复制 |
| `src/simulation/traffic-lights.ts` | 配相、模拟时钟、黄灯决策、全红清空与灯态查询       |
| `src/editor/traffic-light-tool.ts` | 路口选取、添加移除及配时修改事务                   |
| `src/render/traffic-lights.ts`     | 灯杆、左转与普通灯头、停止线和灯态更新             |
| `src/ui/traffic-light-panel.ts`    | 配时浮层、当前状态和相位列表                       |
| `src/simulation/simulation.ts`     | 提供当前车辆占用，调用控制器准入结果               |

`Project.signals` 是可选字段，旧存档默认没有红绿灯。配置绑定道路端点组合，内部自动分段会迁移绑定，整体移动时更新位置。完整路口复制和模板放置会复制配置并重建引用；不完整选择不复制信号配置，避免悬空引用。路口拆除或不再构成三岔路口时清理失效信号。

## 验证与边界

`tests/traffic-lights.test.ts` 覆盖绿黄全红计时、大小时间步一致、启动偏移、保护左转、黄灯近远车决策、实际车辆红停绿行、出口阻塞、已准入车辆清空、对向直行并行、多周期车身分离、高速提前制动、复制与保存，以及碰撞回滚撤销准入。

`tests/browser/traffic-lights.spec.ts` 验证地图添加、配时、相位切换、保存重载、移除与撤销、模拟暂停倍率，以及桌面和窄屏操作。

信号灯不能消除超出道路容量的拥堵。全红等待持续不结束时，应检查出口回堵、车道转向及路口几何；有限倒退恢复也不能保证解开所有高压死锁。尚未按真实交通数据校准。
