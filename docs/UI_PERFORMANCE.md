# 界面与工具切换性能

苜蓿叶40段道路的工具切换曾出现约2秒主线程阻塞。Chrome采样和实际`setTool`计时定位到道路渲染缓存：控制点显隐和选择状态参与整段道路的缓存键，切换工具会重复执行分流铺面裁切、路缘裁切、桥墩净空搜索及网格上传。一次对照操作序列额外创建240次道路网格。

优化后，路面缓存仅跟随道路及相关渲染几何变化失效；选中描边通过替换线材质更新，控制点独立生成、显隐，隐藏时不参与鼠标命中。端点标记复用到道路拓扑变化，信号灯外观只在道路或信号配置变化时重建。没有显示车道路径时，不再为普通工具切换计算整张路网连接。

自动回归在40段真实苜蓿叶地图中连续操作地图菜单、连线、红绿灯、选择、升级和网格开关：验证道路网格ID全部保留、没有重复调用路面生成，并检查同步工具处理低于200毫秒。另验证选择高亮、隐藏控制点命中和真实加车道后的目标／相邻分流路面失效，防止用过期几何换取速度。

测量使用本机Chrome、1440×900视口及相同操作序列，记录`setTool`同步处理时间、CPU采样与道路网格创建次数。它不是跨设备帧率或现场INP保证；真实道路编辑仍有必要的几何生成成本。正式构建前后数据及检查结果见[验证记录](verification.json)。

拾取与世界坐标投影会先核对当前视口比例，处理快速窗口尺寸变化后事件早于`ResizeObserver`的情况。回归包含从390×844立即切回1440×900后投影、点击建路，无需等待固定延时。
