# CSUR 参考与本次应用

本轮研究了用户提供的 [CSUR 主仓库](https://github.com/citiesskylines-csur/CSUR)、[core/csur.py](https://github.com/citiesskylines-csur/CSUR/blob/master/core/csur.py)、[core/assets.py](https://github.com/citiesskylines-csur/CSUR/blob/master/core/assets.py)，并延伸查看 [CSURToolBox 中文说明书](https://github.com/citiesskylines-csur/CSURToolBox/wiki/中文说明书) 和其偏移选取、车道偏移处理。参考源码不包含在本仓库和构建产物中。

## 采用的设计思路

CSUR 主仓库的核心是离线生成道路资产。它用起终点断面及横向位置表达道路，以基础、平移、车道变化、分合流等模块组织资产；半车道位置使不同断面能够组合。CSURToolBox 负责部分游戏内偏移道路选取与平滑处理。

本 Demo 已有实时程序化路面与车道曲线，因此采用断面接口对齐的思路，独立实现适用于当前道路模型的几何计算。可编辑曲线轴线、实际路面中心和车道中心分别计算，避免将三者混为同一个吸附点。

## 现在可操作的效果

- 建造单向道路时，接口对齐默认为自动；在底部小按钮或聚焦地图后按 Tab，切换自动／中线／左缘／右缘。
- 三车道接两车道，选择左缘对齐时，两条保留车道的中心线能精确接上。采用 3.6 米车道时，中心偏移为 1.8 米。
- 三车道接单车道匝道，选择右缘对齐时，匝道对准最外侧车道；同样宽度下偏移为 3.6 米。
- 吸附时显示琥珀色圆环、参考点与短线，文字说明对齐侧及实际偏移米数。断面宽度取自当前资产，不写死 CSUR 的尺寸。
- 对齐沿道路局部横向计算，旋转后的道路同样适用；拓宽路段末端补偿轴线和实际路面中心之间的偏移。
- 城市双向路口和近似垂直接入继续使用共同中心节点。首击先选择偏移接口、随后转向垂直时，预览和最终几何自动回到中心节点，避免断口或额外短段。

实现位于 `src/core/snapping.ts`，由 `Editor.snapped` 和场景预览调用。五项几何回归测试覆盖两车道续接、外侧匝道、渐变末端补偿、旋转接口和城市路口；浏览器测试使用真实指针验证偏移提示、生成后的车道连接，以及起点偏移后向两个垂直方向转出的共享节点和可达路径。

本次没有移植 CSUR 的 Python/Blender/Unity 资产流水线，也未将其车道面板或资产命名体系加入游戏界面。任意位置的平行道路偏移、多个分离车行道及护栏间距组合，不属于当前端点对齐实现。
