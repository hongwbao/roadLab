# 入口车流与出口比例

按 **I** 或点击“设置通行口”进入车流测试。点击已标记的入口，或在左侧入口按钮中选择；未标记的道路端点仍可点击添加通行口，右键取消。

## 总量

本版按用户确认的规则定义：**全局100% × 入口100% = 每个入口总共50辆/模拟分钟**。四个入口均为100%时，总需求为200辆/分钟。50是可调的测试基准，不是所有道路、速度和车型下的物理饱和容量。

入口有四条车道时，每条目标为12.5辆/分钟，合计仍为50；入口只有一条车道时，目标为50。全局200%或入口200%分别将这一入口需求加倍。

当前入口的总量和每条车道的目标值显示在比例输入下方。“100%基准”折叠项可调整1–240辆/分钟；调整时保留各入口百分比。入口百分比允许0–1000%，0%停止该入口的新需求。全局倍率继续使用底栏0–400%。新建入口与内置示例默认100%；旧存档保留实际基准流量，并按50换算成显示百分比。

每个入口的可用同向车道拥有独立的等额预算和等待队列，出车时刻错开。一条车道受阻不会把自己的份额额外灌到其他车道，也不会阻挡其他车道按各自份额出车。实际进入仍需满足车身空间条件；需求大于通行能力时，待进入数量会增加。

## 出口分配

未自定义时，该入口的流量平均分给其他出口。双向通行口兼作入口、出口，但同一端点不作为自己的目的地，沿用原有外部通行口规则。

修改某出口的百分比会固定这个值，其余出口按原比例重新分配剩余部分，例如四个出口25%各自均分，将第一个改为70%后，其他三个各10%。0%不会分配新的车辆。只有一个出口时，可设为100%，或0%暂停。点击“均分出口”恢复自动均分，之后新增出口会自动参与均分；自定义方案新增的出口初始为0%，由用户分配。

目的地在规划车辆时按比例随机抽取，与入口车道独立。相同目的地的车辆能够从不同入口车道出现，随后按照既有实时车道预判选择合法车道；不会为了匹配出口而把某种目的地固定到某条入口车道。短时间观察会有随机波动。

运行中修改入口比例、基准或出口分配，会影响之后分配的车辆，保留现有车辆、计时、统计以及已经规划的道路路线。出入口几何、道路或车道连线的编辑仍按原编辑器规则重置测试。

## 地图提示与保存

悬停出口行、点击出口名称或聚焦其比例输入框时，地图显示从当前入口指向该出口的青色虚线和箭头，并以琥珀色圆环突出目标。面板同步显示“入口n → 出口n”。虚线表达出行分配，不表示车辆必须沿着这条几何曲线行驶；离开工具时隐藏。

入口流量仍以`Port.rate`保存，`Project.trafficBaseRate`保存100%基准，`Port.destinations`保存引用端点和相对权重。省略分配字段表示自动均分。地图自动保存、命名存档、JSON导入导出和撤销/重做均保留配置；道路分段或反向时按原物理出口更新引用，移除出口会清理其引用。无出口或全部出口权重为零时，暂停新需求，不积累没有目的地的车辆。

本功能不新增道路或车道规则，不放宽碰撞检查，也不保证不可达出口能够出车。测试应连接相应道路；不可达行程沿用原有失效行程统计。
