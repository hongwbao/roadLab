# 路线提前准备与相邻变道

本模块是 RoadLab 的路线准备策略，位于实际 source runtime 的宿主层；原式车道选择、导航和车辆运动算法模块未改写。

车辆依据自定义车道连线，在已选路线中查找前方第一个限制出口车道的连接，例如只有最右侧车道可右转。策略通过连续道路片段及直行连接，把可用出口车道反推到当前路段。每条待跨越车道增加约5秒、至少45米准备距离，结合当前速度计算启动范围，最多600米；已在合适车道的车临近出口时保持该车道。结果按车辆路径和当前片段缓存，路径变化时重算，车辆离开时清理。

每次只选择同向车道组中的一个相邻车道。连续跨车道时先完成当前相邻变道；目标车道按真实车辆纵向位置检查前后空隙，前方至少6米或1.1秒车距，后方至少6米或1.3秒车距。空间不足则等待下一次机会，保留原路线。进入受限连接前，未完成变道的车辆会提前减速并等待空隙；已经开始的相邻变道允许缓行完成，避免未对齐就切进路口。底层速度与碰撞检查继续生效。

验证包括四车道最左侧车辆驶向最右侧专用右转出口：旧运行链在同一测试中一次跨越3条车道；新链按1→2→3逐条准备并完成右转。另检查上游距离计入准备范围、前后安全间隔，以及已有实际引擎回归。指标为特定测试场景，不代表所有拥堵问题已经解决。此前持续高压下的车身重叠检查仍保留独立验证。
