# 固定道路路线与实时车道预判

RoadLab 在宿主策略层实现这套行为，接入实际 source runtime；底层导航、车辆运动和碰撞保护继续使用原有模块。这是按本项目需求实现的策略，不代表已完整复刻《都市：天际线 II》的交通系统。

## 道路路线与车道分工

车辆出发前完成全局寻路，固定道路及连接序列。车道不随这次寻路锁定：行驶时依据实际连接、路口自定义连线以及周围车辆实时选择。原运行链请求修复路径缓冲时，从最初路线的当前位置恢复剩余序列，不重新选择另一组道路。

默认预判距离为 **500 米**。从“地图菜单 → 交通 AI 设置 → 车道预判距离”可调整为 **100–2000 米**。参数随地图保存；旧地图缺省为500米。运行中修改保留车辆、时间和统计，下一模拟帧更新预判缓存，不重新编译路网或重建路面。

## 预判与执行

1. 从当前位置沿既定路线计算移动窗口，包含道路拟合片段、连接和后续道路。窗口随车辆行驶前移，不能把刚进入长道路时的结果缓存到整段道路结束。
2. 使用实际编译路网的后继关系，倒推哪些当前车道可抵达路线中的后续连接。自动连接与自定义连线采用相同检查；未来普通车道组允许相邻变道，路口连接内禁止横向变道。以剩余所需变道次数选择合适车道。
3. 当限制进入窗口，立即开始准备。每次只移向相邻同向车道，完成后再进行下一次，不直接跨越两三条车道。普通超车也受相邻车道、安全间距及路口前距离约束。
4. 前方空隙至少6米或1.1秒车距，后方至少6米或后车1.3秒车距。占用检查按整条道路的行驶方向统一纵向坐标，跨拟合片段仍可看到目标车道上的车辆。
5. 多车准备时按到达限制位置的预计时间及稳定车辆编号协调。所需中间车道的邻近后车可提前适度减速留出空隙；同一目标空隙只允许一个请求。同侧已开始的变道受保护，对向换道请求通过优先顺序错开，避免同时互等。
6. 下一段连接必须是当前实际车道的合法后继，不能借队列跳到不相连的出口。未完成横向移动时不能直接进入路口连接。

通常的提前准备不附加减速。确实一直没有安全空隙时，最后的安全等待位置在连接上游约25–60米；已经开始的变道可缓行完成。这个边界避免停在线前才临时横跨，并不保证超饱和路网永远不会排队。红灯、前车堵塞和真实车身碰撞保护仍能让车辆停车，不能用穿模、强行换路或瞬移消除真实拥堵。

## 性能与验证边界

车道可达性按车辆当前路径组、组索引及移动窗口终点缓存；只有窗口跨过新片段、车辆换组或参数变化时重算。局部空隙协调使用当前车道占用快照，不为每辆车每帧执行全路网寻路。

自动化验证包含：移动窗口跨多条道路和连接的倒推、自动和自定义专用右转、相邻连续变道、四辆并排行驶的让出空隙、实际显示车身不重叠、固定路线的路径缓冲修复，以及运行中参数调整和存档恢复。测试场景通过不等于所有道路规模或拥堵形态已经解决；持续高压下既有的独立碰撞回归仍保留原断言与失败记录。
