# 出发前按预计用时选择道路

RoadLab 的道路路线在出发前决定，行驶时实时选择车道。目的出口先由入口的出口比例随机分配，然后在去往这个出口的合法道路中寻找预计用时最短的路线；不会为了缩短路线改变目的地。

道路限速原本就进入了寻路的速度估算，但先前沿用综合权重：时间、按里程附加的成本和转向舒适度一起计分，另有随机扰动。这不保证优先选预计最快的路。

现在宿主层的出发查询使用时间权重`[1,0,0,0]`和稳定搜索。底层原式寻路、车辆运动与车道连接规则保持独立；此处是本项目的选路偏好，不宣称完整复刻原游戏的所有出行行为。

预计用时主要来自各段长度除以可用速度。可用速度取道路限速和车辆最高速度的较小值，并应用已采样的道路交通速度修正；弯曲道路的时间成本仍参与估算。道路的所有车道目前共用该路段的最高限速，尚未提供单车道限速设置。

里程和舒适度不再作为额外目标压过时间，也不会因为随机成本缩放选到明显更慢的路。禁行、单向和自定义连接仍是约束。道路路线确定后保留原来的固定路线机制；之后的拥堵不会触发每帧全局重寻路。交通采样更新会影响后续出发的车辆。

这是预计时间，不是对未来实际抵达时间的保证。目前没有完整计入每个信号灯的等待时长和未来排队变化。

专项验证包含：1公里25km/h与4公里120km/h的成本反例，实际路网中8个随机种子均选择更长但更快的道路，改动限速后重新出发换选，以及自定义连线禁止快路时必须走合法慢路。车辆极速上限和已采样拥堵修正也有验证。
