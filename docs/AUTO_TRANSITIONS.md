# 节点平滑显示

新建道路和单侧加车道仍直接连接。在升级工具中选择“平滑节点显示”，悬停两条道路的连接节点并左键应用；右键取消该节点，或选择“取消节点平滑”。同一路段两端独立，鼠标离开或切换工具会清理临时预览。

平滑只改变局部铺面和标线显示。道路控制点、真实断面、车道数量和方向、车道连接、停车线、车辆路径及碰撞输入始终使用关闭平滑时的逻辑。真实`profile`、道路偏移和中央隔离带仍属于功能性几何，添加或修改这些功能会正常重建交通。

## 逻辑与显示边界

`src/core/math.ts`的`laneWidth/lanePoint/nodePoint/center/pavementWidth/medianWidth`仅计算真实道路，不读取旧`autoTaper/transitionMode`。连线工具每个路臂只使用一个逻辑曲线参数；3→5时五个出口横向并排，开关平滑不移动任何一个圆点。不再为个别车道搜索宽度根或后移连接端点。

`src/core/road-visual-settings.ts`在现有Project v1中管理独立可选数据：

```ts
roadVisuals?: {
  version: 1;
  nodes: { arms: { road: string; end: 0 | 1 }[]; smooth: true }[];
}
```

节点身份由完整道路端点集合确定。缺少记录表示直接显示；取消后保留已迁移标记，不会由旧road标志重新开启。显示设置随地图、模板和历史保存；拆分、反向、复制与删除维护相应引用。

旧地图载入时，仅把旧road级平滑意图迁移到实际已有连接节点。`autoTaper`是旧派生缓存，迁移后丢弃；不会改写真实控制点或profile。普通直接连接的地图不新增空显示字段。显式`to: []`继续表示禁行，不能推测它曾经是不是被旧版本误清空。

## 可见铺面与标线

`src/render/road-visual-geometry.ts`读取真实道路、连接和节点显示设置，派生局部铺面。基底保留完整逻辑车道；必要接缝补面覆盖车辆转向包络。开启平滑可以向外补足较窄端或偏移侧的接缝，不能将较宽道路压窄、缩掉有效车道或移动车辆。真正路口继续保留路口铺面和斑马线，不铺满普通道路标线。

`visibleRoadSurfaceTriangles(project)`提供与Scene使用同一计划的完整可见面，包括道路条带、节点补面、平滑扩展和真实路口铺面，供车身包络验证。只检查两条原始道路条带无法代表最终渲染结果。

`transitionMarkings`只读最终合法连接。相邻、独占、保序且真实几何相接的分隔线可以延续；多目标、汇流、交叉、禁行和横向跳接在局部留白，不将J工具辅助线当作道路标线。实体隔离带和真实车道轨迹不由画线反推。虚线仍按米制3m实线/6m间隔重复。

## 运行中的操作

纯显示应用、取消、悬停和历史恢复只更新渲染及保存，不调用`autoJunction/stopForEdit/prepareForEditing/configure`。视觉撤销重做保留同一个Project对象，确保运行中的流量和预判距离设置仍绑定当前地图。路网、车辆实例、信号controller与时钟不因显示操作重置。

正式道路、路口和信号几何缓存与节点显示缓存分开。真正道路升级仍走原编辑事务；本阶段没有替换节点拓扑或完整CS2建路管线，也没有处理独立登记的非对称交叉缺陷。

## 对应验证

核心覆盖位于`road-visual-settings`、`auto-transitions`、`smooth-join-lane-ports`、`road-visual-geometry`、`transition-markings`及交通不变量测试。浏览器覆盖真实建造3→5、J拖线、节点左右键、历史与重载、运行中零重配和参数绑定。真实交通测试保留完整车身边界检查；旧direct逻辑本身已有的高流量重叠以固定时间轴对照记录，不能声称本次显示解耦消除了它。

确切固定源码、测试结果与发布状态以本轮交付记录为准；本文件不以过去发布的测试数替代新版本验收。
