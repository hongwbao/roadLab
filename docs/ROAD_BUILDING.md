# 车道级道路建造

支持车道级接头、单侧扩宽、非对称断面和路口车道连线。沿用底部资产栏、地图预览和鼠标建造；平行道路、环岛、网格和隧道工具仍暂不纳入。

## 接到指定车道

选择单向道路资产，保持“车道吸附”开启和“对齐：自动”。鼠标靠近已有道路端点时，高亮目标车道并显示编号。单车道可选择任意同向车道；多车道选择保持左右顺序的连续车道组，例如两车道接四车道时可选择 1–2、2–3 或 3–4。

起点和终点都可以吸附。直接移动鼠标选择目标；画布聚焦时按 Tab 切换附近候选，Shift＋Tab 反向切换。Alt 临时关闭吸附。关闭“车道吸附”后仍可使用原来的中线、左缘和右缘对齐。

车道从行驶方向的左侧开始编号，消失或尚未长出的车道不参与该位置的编号。可接入双向道路中方向匹配的一侧；新建的双向道路仍使用整幅端点对齐。不同高度的道路不作为同层吸附候选。

接头匹配目标车道的位置、切线和坡度。吸附选择保存为道路端点上的车道对应关系，参与自动连接与寻路；不是单纯的视觉偏移。保存载入、撤销重做、内部道路分段、复制和模板放置均维护这些引用。删除目标道路会清除引用；反转单向道路会恢复接口及转向规则为自动状态。不同车道宽度的道路可通过短连接曲线衔接，整段道路仍使用其资产车道宽度。

## 增减车道与分合流

正向、反向数量可以分别调整，每个方向为 1–6 条。选择单向道路资产，再点“加车道”，在路段的一侧悬停并点击，向该侧增加对应数量的车道；原有车道保持原位，双向道路可形成 2＋3 等非对称断面。

新建或扩宽默认直接连接。两车道先接入三车道的两条车道后，可再把独立单车道吸附到空余车道，手工拼出汇流；分流同理。资产栏不再提供独立的分合流资产。需要平滑渐变时，在“升级”中选“添加平滑过渡”并点击较宽路段；“恢复直接连接”移除渐变。旧地图的已建渐变和分支几何保持兼容。详见 [单侧扩宽与手动过渡](ROAD_EXPANSION.md)。

从已有主线中段接出时，选择匝道资产，将起点移到外侧车道。此模式只对车道数固定的单向主线提供中段候选，自动处理内部道路分段，保留主线直行，并让匝道沿目标车道方向起步。不能从侧面直接穿过外侧车道接入中间车道；普通横向接入继续生成交叉路口。复杂的渐变主线中段和双向主线中段匝道不在当前自动处理范围内。

## 车道转向

按 J，或点击左侧“车道连线”，再点击路口。选入车道实心圆点，再选出车道空心圆点，添加或取消曲线连接；同一入车道可连接多个目标车道。右键连线删除，也可恢复单车道或整个路口的自动连接。规则进入真实寻路并随地图保存。详见 [路口车道连线](JUNCTION_LANE_CONNECTIONS.md)。

## 实现与验证

- `src/core/lane-rules.ts`：车道组、编号、持久接口和转向方向。
- `src/core/snapping.ts`：车道锚点及原有断面对齐。
- `src/core/model.ts`：连接推导、导入校验、分合流和引用维护。
- `src/editor/editor.ts`：候选选择、建造事务及车道转向操作。
- `tests/lane-building.test.ts`：指定车道、成组接头、双向目标、保存分段、左右分流、多上游接入、转向可达性及车辆实际通行。
- `tests/browser/editor.spec.ts`：真实鼠标操作、Tab、存档恢复、撤销重做、中段匝道和桌面／窄屏控件检查。

默认运行源派生交通内核；可以添加 [红绿灯](TRAFFIC_LIGHTS.md) 控制路口。高流量长期死锁等已知限制仍见 [交通 AI](TRAFFIC_AI.md)。
