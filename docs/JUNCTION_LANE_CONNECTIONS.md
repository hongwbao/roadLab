# 路口车道连线

按 J，或点击“车道连线”工具，再点击三岔、十字路口中心。
地图会显示路口轮廓、青色通行曲线、实心入车道圆点和空心出车道圆点。

- 点击入车道，再点击出车道，添加连接；再次点击已连接的出车道，移除连接。
- 同一入车道可连接多个出车道，包含原自动规则未分配的目标车道。
- 点击一条曲线可选中它，按 Delete 或面板按钮删除；右键曲线也可直接删除。
- “禁止全部出口”明确关闭选中的入车道。“此车道恢复自动”和“整个路口恢复自动”撤销相应自定义规则。
- 右键空白取消当前选择。J 或 Esc 退出工具。折叠的“按名称选择车道”提供键盘按钮操作。

所有规则作用于实际寻路和驾驶网络。编辑会重置交通测试，并随地图自动保存，支持撤销、重做和 JSON 地图导入导出。

## 数据与生成

`Project` 和 `Blueprint` 的可选 `junctionLaneConnections` 存储每个源进口车道的完整目标列表：

```ts
type JunctionLaneEndpoint = { road: string; lane: number; end: 0 | 1 };
type JunctionLaneRule = {
  from: JunctionLaneEndpoint;
  to: JunctionLaneEndpoint[];
};
```

没有规则时使用原自动连接；`to: []` 是明确禁行，不能当成缺省配置。
只有配置过的源车道被替换，其余车道继续使用自动连接。自定义连接优先于原来的粗粒度转向限制。
旧地图没有此属性，连接行为不变；退役的 `Project.connections` 字段仍不使用。

核心模块枚举同一路口的全部合法入/出车道对，而不是仅过滤原自动结果。
不能跨层连接、连接另一处路口、连接入车道作为出口，或连接同一道路掉头；物理车道吸附关系仍须满足。
拆分道路时，原终点的引用迁移到后段 ID。道路拆除、车道消失或路口移开后会清理失效引用。
保留有效源车道的空目标列表可以避免删除某个出口后重新开放其他方向。
复制和模板只携带所有引用道路均被复制的完整规则，并重映射道路 ID。

`applyJunctionLaneRules` 在没有自定义数据时直接返回原自动数组，避免额外扫描路口。
`junctionLaneLayout` 使用实际路口 trim 和有灯时的停止线偏移，曲线与当前驾驶系统一样采用
两端切线和 0.45 倍端点距离的控制柄。显示层只抬高曲线以避免道路表面遮挡，不改变驾驶轨迹。

## 验证范围

`tests/junction-lane-connections.test.ts` 的 28 项测试覆盖新增非默认车道对、多出口、禁行、旧转向覆盖、
保存、撤销、拆分/拆除/升级清理、复制、非法输入，以及曲线端点/切线和信号停止线。
其中两项直接构造 `Cs2TrafficSimulation` 并检查真正的 `connectionLaneIds` 和驾驶曲线，验证规则进入运行中的网络。
限定严格 TypeScript 和这些文件的 Prettier 检查通过。

`tests/browser/junction-lane-connections.spec.ts` 提供实际鼠标圆点操作、存档重载及紧凑屏键盘焦点回归。
浏览器验证和部署由集成会话在固定源码快照上统一完成，本模块交付时不宣称这些浏览器检查或上线已经完成。
