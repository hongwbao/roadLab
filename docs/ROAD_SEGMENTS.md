# 长道路自动分段与简化标线

新建长道路时，按曲线的实际弧长等分，默认单段不超过约 120 米。300 米直路会生成 3 段，600 米直路会生成 5 段；拖动时先显示计划节点，建成后是可以单独选择、调整和拆除的真实路段。

分段节点以小圆点显示，保持原有直线、弯道、坡道和车道渐变。相邻路段自动建立车道连接，内部节点不会变成额外路口，也不会添加交通出入口。连续建造从最后一段末端继续，删除中间一段不会连带删除整条道路；撤销和存档沿用已有机制。

道路资产缩略图与常规路面不绘制重复方向箭头，保留车道线、道路边缘线及双向中线。建造预览、车道吸附和转向编辑中的临时方向提示继续保留，方便判断连接方向。

## 模块接口

`src/core/road-segments.ts` 不依赖界面或 Three.js：

- `MAX_ROAD_SEGMENT_LENGTH`：默认 120 米。
- `roadSegmentCuts(road, maxLength?)`：返回原道路参数空间中的分割位置，按弧长均分。
- `roadSegmentNodes(road)`：返回预览节点。超出预算的极端预览返回空数组，避免渲染循环异常；提交时仍明确报告长度或数量限制。
- `segmentRoads(project, ids, maxLength?)`：只处理指定的新建道路，原地更新项目，并返回“原道路 ID → 按行驶轴线顺序排列的各段 ID”。调用方应放在已有编辑事务中。

分割复用模型的 `splitRoad`，维护车道渐变、端点车道引用、通行口及红绿灯道路引用。先按中点递归拆分，避免公里级道路在顺序切分时触发端点 2.5% 的保护范围。项目最多 1,000 段；超预算计划会在修改前拒绝。

本功能只拆分本次新画出的道路及其分合流分支，不自动改写已有存档。原始曲线中的异常参数布局仍可能触发模型的分割保护，编辑事务会回滚并提示调整长度。

## 验证

```bash
npx vitest run tests/road-segments.test.ts
PLAYWRIGHT_PORT=5174 npx playwright test tests/browser/road-segments.spec.ts
```

5 项核心用例验证直路分段、弯曲拓宽及高度保持、车道引用和通行口维护、6 公里道路、预算拒绝，以及车辆连续通过内部节点。2 项浏览器用例验证预览节点、局部拆除、撤销、连续建造和无箭头缩略图。整合版本由主会话统一检查和部署。
