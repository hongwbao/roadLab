# 道路升级与右键反向操作

按 U 进入升级，选中项目后左键应用，右键点道路执行该项反向操作。操作后继续保持升级模式；右键空白处或 Esc 仍可退出。各项操作支持地图撤销／重做。

| 升级项目     | 左键                   | 右键                                       |
| ------------ | ---------------------- | ------------------------------------------ |
| 中央隔离带   | 添加／调整所选宽度     | 移除该路段的隔离带                         |
| 加车道       | 在悬停一侧增加所选数量 | 在悬停一侧减少相同数量，每方向至少保留一条 |
| 添加平滑过渡 | 使相邻普通断面平滑衔接 | 取消过渡，恢复直接连接                     |
| 恢复直接连接 | 保留完整断面直接接入   | 恢复平滑过渡                               |
| 替换道路     | 应用所选道路资产       | 恢复上一次替换前的断面                     |

道路替换恢复记录随地图和模板保存，只保留该路段最近一次替换；没有恢复记录的旧路段会提示没有可恢复记录。恢复断面保留当前道路控制点。减车道会移除已删除车道的连线和吸附关系，并重排存留车道的索引。

平滑过渡现在同时处理车道数量、中央隔离带宽度和横向位置：同样2＋2可以从无隔离带接入2米隔离带，也可以从2米过渡到4米；等宽断面偏移几米也可以平滑接入。3＋2接2＋3时，两侧通过共同2＋2接头再回到各自断面。只为可辨识的双路段接头生成过渡，多臂路口与分合流连接保留各自通行空间。两端都有过渡的短路段会限制过渡长度，避免互相覆盖。

隔离带实体、路面、标线、斑马线和真实车辆车道曲线读取同一套局部断面宽度。悬停预览使用独立路网副本，不改写存档；与接缝相关的相邻路段会同步刷新，避免缓存旧收口留下黑色缺口。

## 替换道路的对齐与预览

选中“替换道路”并选择资产，把鼠标移到旧路面的不同横向位置，自动选择最接近的对齐方案。两车道换单车道可以中线对齐，也可以保留原第1或第2车道的位置；多车道还会枚举同向连续车道组及道路边缘。双向非对称道路与中央隔离带的实际宽度也纳入计算。

地图获得焦点时按 Tab／Shift＋Tab，或点资产栏“替换对齐”，在自动、中线及当前道路可用的车道／边缘方案之间切换。状态栏显示本次方案和米数偏移。选择的偏移保存在道路断面上，不移动原始控制点。预览和提交调用同一断面计算；悬停时隐藏旧道路及相关路口铺面，显示蓝色替换结果，离开后恢复。预览不会写入地图；左键应用，右键恢复最近一次替换断面，撤销／重做和保存仍可使用。

选中道路的信息面板提供“最高限速”，可输入5–160 km/h的整数。修改使用普通编辑事务，会暂停当前测试并清除运行车辆；重新开始后，真实车道网络使用该限速。限速随地图保存，可撤销和重做。弯道、前车与路口等因素仍可使实际速度低于上限。

道路分道虚线按实际三维曲线距离绘制，实线段3米、间隔6米。拉长道路会增加标线数量，缩短时减少，末端允许出现被截短的一段；路缘实线与中央分隔线保持实线。

车道连线既支持同高度、共享端点的多臂路口（端点容差0.65米），也支持偏移吸附形成的分流、汇流与两路段偏移接入。识别依据真实端点与车道连接关系，支持五岔或更多；不会按平行外观合并无连接的道路。普通两段直线接缝不自动成为编辑路口，上下层交叉也保持独立。
