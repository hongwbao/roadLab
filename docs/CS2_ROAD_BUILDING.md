# 原式道路建造接线

用户已将道路建造复刻置于当前开发首位。原版道路工具与节点车道生成继续分模块恢复；本文件只描述已经实际接入编辑器的部分。

## 已接入的建路流程

`Editor.draft` 调用 `buildCS2RoadLabCourse`，根据两点或三点输入执行完整 `NetToolSystem.CreateDefinitionsJob` 的 Straight/Simple 课程事务，再把生成的 NetCourse 曲线映射为本项目 Road 的控制点。实时预览和最终提交都经过该入口。

三点曲线现在采用原版基于道路宽度的窄角控制点修正、FitCurve 控制柄、LinearizeElevation 和 CoursePos，而不是固定二分之三控制柄。直线也经过相同的源建造事务。Course 的创建定义、Updated、NetCourse 等命令保留在适配器返回结果中，便于追踪；RoadLab 的创建事务负责最终插入道路、历史、保存和派生路网。

完整原式模块是 `cs2-road-courses.ts`；共用数学是 `cs2-net-geometry.ts`。前者有原方法体与字典世界 oracle，后者使用直接原 DLL 函数。几何输入相同不等于完整原 Unity 建造世界已经运行。

## 本项目资产与世界映射

- 本项目的道路资产以名义车道数、单双向和每车道宽度计算 defaultWidth。它们是 RoadLab 资产，不冒充已恢复的天际线序列化 prefab。
- 允许建造高程 `[0,80]` 与现有界面一致；maxSlopeSteepness=0.15 是显式本项目策略，使源工具允许坡道。建造高度步长仍由现有工具控制。
- 当前地图是地面高度为0的平面。控制点 elevation 对应其离地高度；不添加虚构的原城市地形、水域或建筑归属。
- 现有道路映射为 Edge，端点按其真实中心位置映射为 Node。中段吸附保留被选道路与曲线参数，用于源 GetCoursePos 的分割身份。
- 普通当前建造没有建筑 owner、装饰生成或平行道路。若未来世界确实需要未实现的 native 依赖，返回 pending/错误，不能跳过后继续提交。

## 仍在替换的部分

当前端点/车道吸附、指定车道组附件、连续建造时的切线约束、自动过渡和路口创建仍包含原编辑器适配。源吸附模块与完整节点车道创建正在接线；这次曲线替换不代表全部道路建造已复刻完成。复杂/连续曲线内核的独立实现也不等于已经增加对应玩家工具。

既有地图继续读取存储的控制点，不在载入时重新拟合旧曲线。新的建造使用源工具曲线，撤销、重做和保存保留实际建成的控制点。

## 验证

- 共用原式几何721项通过，包含719个直接原DLL场景。
- RoadLab世界适配3项检查四分之一圆、源命令、道路/中段身份、高程及输入不变性。
- 浏览器真实三次点击检查新控制柄、预览与提交一致，以及撤销重做和保存重载后的几何保持。测试坐标选择在地图可点击区域，避免点到底部资产栏。

完整 Course 和吸附模块的覆盖范围、来源与未实现依赖以各自文档为准。最终整合版本还需在固定生产构建上验证道路、车道附件、自动路口、红绿灯和运行链路。
