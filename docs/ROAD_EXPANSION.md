# 单侧扩宽、非对称道路与手动过渡

进入“升级 → 加车道”，选择单向单车道资产，将鼠标移到已有路段的左侧或右侧，查看新增车道的预览和行驶方向，再点击确认。添加使用已有道路的车道宽度、速度和高程，只改变当前独立路段；长路已经自动分段时，可分别扩宽各段。

- 单向两车道可以在任意一侧加成三车道。
- 双向 2＋2 在正向一侧添加后成为 2＋3，在反向一侧添加后成为 3＋2。
- 可选择多车道单向资产一次添加多条，每个方向上限六条。
- 城市资产栏也提供 1＋2 和 2＋3 道路；正向、反向车道数可分别调整。

新增车道占据选中一侧的空间，原有车道中心线保持原位。路口连线、端点车道吸附和原转向规则的车道引用会同步迁移。地图保存、撤销、复制和自动分段继续保留断面。渐变中的旧路段需先用“升级 → 替换道路”变为等宽断面，再添加车道。

## 直接连接与平滑过渡

新建和扩宽默认保留完整车道，不自动缩窄端点。两车道可以先接入三车道中的两条，再将独立单车道接入空余车道；分流可以反向组合。这些接头使用普通道路和车道吸附完成，资产栏不再提供独立的汇流、分流或渐变资产。旧地图已建成的分合流几何仍保留。

需要平滑过渡时，选择“升级 → 添加平滑过渡”，点击较宽路段。系统在同高、同向且车道数兼容的窄路接头处生成平滑渐变，双向道路分别保留正反向的车道数。真实交叉口或已由多个分支占用的接口保留完整宽度。过渡意图随地图保存；移动或删除邻路后，根据实际接头重新计算。

选择“升级 → 恢复直接连接”移除该路段的端点渐变，重新开放完整断面供分支接入。默认的“替换道路”仍按选中的资产更换道路。

## 编辑性能

道路建造的交叉检测先比较包围盒，并复用曲线采样。场景复用未变化路段的网格和标线；车道连线修改不重建道路网格。车道合法性检查只建立端点对应关系，缓存不会因连线权限或相位时间改变而失效，也不生成绘图用的整批曲线样本。

编辑期间只更新拓扑、信号预览和路线摘要；点击“开始测试”时，使用最新地图构建实际车辆运行网络。连续修改不会重复编译车辆网络，已开始的交通测试在道路编辑后仍会重置。摘要不替代运行时的真实车道寻路结果。

固定版本的构建、测试、浏览器操作和性能对照见 [验证记录](verification.json)。性能测量是本机浏览器中指定路网的操作耗时，不是任意规模地图的帧率保证。现有高压车辆重叠问题仍单独记录。

本机固定场景对照（64 段道路、16 个双向路口、每向两车道，无通行口）：

| 操作               | 上一版                   | 本版                  |
| ------------------ | ------------------------ | --------------------- |
| 连线修改（三次）   | 687.5 / 662.4 / 689.5 ms | 17.9 / 15.4 / 12.9 ms |
| 新增独立 80 m 路段 | 3585.3 ms                | 37.5 ms               |

两次建路后均有 65 段道路。以上测量包含实际编辑事务，完整车辆运行网络在开始测试时构建，不能将延后初始化表述为运行时计算被消除。

升级模式下右键悬停一侧可以减少所选数量车道，至少保留每方向1车道。减少时会同步清理已删除车道的连线和吸附引用。
