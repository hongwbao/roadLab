# 中央隔离带与升级工具

点击底部“升级”（快捷键 U），在同一菜单选择“替换道路”“加车道”“中央隔离带”“添加平滑过渡”或“恢复直接连接”。加车道已从独立建造按钮移入升级菜单，仍按悬停道路的左右侧决定扩宽方向，默认选用单车道。

## 中央隔离带

所有道路每车道统一 4 米。旧存档和模板载入编辑器时同步转换，原有车道数量、标识和隔离带宽度保留；随车道宽度计算的扩宽偏移按比例更新。双向 2＋2 的行车道总宽为 16 米，加 2 米中央隔离带为 18 米，不含路肩。

选择“中央隔离带 → 添加／替换”，再选择 1、2 或 4 米宽度。悬停双向路段查看真实断面与实体预览，点击应用；选择“移除”后悬停、点击可恢复原断面。支持连续应用、撤销／重做、地图保存、复制、模板和道路自动分段。单向道路显示不适用提示。

隔离带是沿道路曲线布置的抬高混凝土岛，计入铺面总宽度并将正反向车道各向外移动半个隔离带宽度。车道数量、索引与原节点身份保持；车辆运行网络和车道连接预览使用同一套车道坐标。隔离带在路口及斑马线前收口；连续同宽隔离带在普通分段接头处保持衔接。宽度调整和移除也会重新计算路面、车道位置、接头与路口。

项目数据使用可选的 `Road.median = { kind: "concrete", width }`。旧地图缺省为无隔离带；导入校验双向属性、实体类型和 0.5–6 米有效宽度，界面提供 1／2／4 米快捷项。隔离带宽度不计入车道数。

## 斜交路口的斑马线

原实现只用道路总宽的一半估计路口半径，斑马线固定在缩进后两米。单侧扩宽改变路面偏移，锐角支路的铺面还可能在路口外继续重叠，导致斑马线侵入铺面或交叉。

现在按实际路面边缘、横向偏移和进口夹角计算各进口的缩进。斑马线需同时避开路口多边形和其他进口的实际铺面三角形，并避让中央隔离带；停止线、信号灯和实际车辆停止位置使用同一结果。锐角路口可能因此占据更长的道路。极短的锐角进口没有足够净空间时，不在冲突区绘制斑马线。

几何布局按道路状态缓存，车道连线和相位配时不会重复生成整批铺面。渲染继续复用未变化的道路和路口模型。

## 验证范围

原始 30° 三岔路口、双向 2＋2 单侧加成 2＋3 的场景已独立复现失败。回归覆盖左右扩宽、不同夹角、弯曲进口、有／无隔离带及短进口；用独立多边形裁剪检查斑马线与路口、相邻铺面的实际交叠面积。

浏览器回归还读取实际 GPU 网格坐标核对几何，检查停止线与交通内核的停止位置一致，并验证升级菜单、预览、宽度切换、移除、保存、撤销和窄屏布局。发布版本与验证结果见 [验证记录](verification.json)。
